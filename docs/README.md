# AIPM Documentation

This folder contains maintained user and product documentation. Historical construction artifacts are collected in [`project/Build-History-Archive.zip`](project/Build-History-Archive.zip) and are not part of normal use or release packaging.

| Location | Purpose |
| --- | --- |
| [`guides/`](guides/README.md) | Beginner guides in English and Arabic. |
| [`project/Architecture/`](project/Architecture/Plugin-Distribution-Architecture.md) | Current AIPM architecture, repository map, capability flow, and Plugin distribution workflow. |
| [`project/Support-Matrix.md`](project/Support-Matrix.md) | Verified local environments and owner/host checks that remain unverified. |
| `project/Release-Notes-v*.md` | Release history and user-facing changes. |
| `project/Provenance/` | Retained source, license, migration, and integrity evidence. |
| `project/Project-Rules.md` | Detailed project contribution and governance rules. |

Start with the guide for your language. Use the architecture and support documents for current structure and verified boundaries; use the build-history ZIP only when historical implementation evidence is needed.
