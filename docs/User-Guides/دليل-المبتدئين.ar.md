# دليل المبتدئين إلى مدير المشاريع بالذكاء الاصطناعي

مرحبًا بك في **AI Project Manager (AIPM)**. يشرح هذا الدليل، خطوة بخطوة، كيفية الحصول على المشروع وتشغيله وفهم شاشاته واستخدام قدراته المعتمدة بأمان، حتى لو كانت هذه أول مرة تتعامل فيها مع المشروع.

> **مهم:** واجهة PowerShell وأوامر `aipm` الموثقة للقراءة فقط. هذا الإصدار لا يوفّر أوامر CLI أو TUI لإنشاء المهام أو تعديلها. حزمة Agent Bridge عيّنة تم التحقق من تنسيقها فقط؛ وليست وكيلًا مثبتًا أو إذنًا تلقائيًا لقراءة ملفاتك.

## 1. ما وظيفة AIPM؟

ينظّم AIPM معلومات المشروع بطريقة واضحة تستند إلى الحالة والأدلة، ليساعد الأشخاص ووكلاء الذكاء الاصطناعي عند العمل المشترك:

| الجزء | معناه ببساطة |
| --- | --- |
| Core Engine | يقرأ حالة المشاريع والمهام المسجّلة ويتحقق من صحتها. |
| Capability Library | يحتفظ بفهرس معتمد للمهارات والمطالبات مع الإصدار والمصدر وسجل السلامة. |
| PowerShell TUI | لوحة طرفية تعمل بلوحة المفاتيح وتعرض البيانات للقراءة فقط. |
| Project Agent Bridge | يشرح طريقة تكامل وكيل متوافق؛ أما الحزمة الموجودة فهي عيّنة محلية غير مثبتة وغير نشطة. |
| Host Adapters | يصف التكاملات والصلاحيات المسموحة ويرفض افتراضيًا العمليات غير المدعومة. |

## 2. جهّز جهازك

يعمل المشروع على Windows مع **Windows PowerShell 5.1** أو **PowerShell 7.x**، ويظهر أمر الإصدار الأخير باسم `pwsh`. ثبّت أيضًا **Python 3.10** أو أحدث، وتأكد من أن أمر `python` يعمل في نافذة طرفية جديدة. التنقل بلوحة المفاتيح يحتاج نافذة تفاعلية حقيقية مثل Windows Terminal؛ أما الأنابيب والمخرجات المعاد توجيهها فليست جلسة تفاعلية.

تحقق من الأدوات:

```powershell
python --version
pwsh --version
```

إذا لم يكن PowerShell 7 مثبتًا، يمكنك استخدام Windows PowerShell 5.1.

## 3. احصل على المشروع

إذا كان لديك حق الوصول إلى مستودع GitHub الخاص بمالك المشروع، استنسخه هكذا:

```powershell
git clone https://github.com/Abdulrahman3M/AI-Project-Manager-AIPM.git
Set-Location AI-Project-Manager-AIPM
```

وإذا استلمت ملف ZIP، ففك ضغطه في مجلد تملكه وافتح PowerShell داخله. مجلد المشروع الرئيسي هو المجلد الذي يحتوي على `README.md` و`VERSION` والمجلدين `Core-Engine` و`TUI`.

قبل استخدام ملفات المشروع أو إعادة توزيعها، اقرأ [رخصة الاستخدام الشخصي الخاصة بـAI Project Manager](../../LICENSE).

## 4. تعرّف على المجلدات الأساسية

لا تحتاج إلى فتح كل الملفات قبل البدء. هذه أهم المواقع للمستخدم الجديد:

| المجلد أو الملف | وظيفته |
| --- | --- |
| `README.md` | تعريف مختصر بالمشروع وروابط البدء. |
| `Core-Engine/` | معالجة الحالة ومحرك القراءة من سطر الأوامر. |
| `TUI/AI-Project-Manager/` | التطبيق الطرفي ووثائق استخدامه. |
| `01-Skills-General/` | المهارات العامة التي يديرها مالك المشروع. |
| `02-Prompt-General/` | مطالبات مستقلة قابلة لإعادة الاستخدام. |
| `Capability-Library/` | الفهرس المحمي وتعريفات مهارات AIPM الأولى. |
| `Plugins/aipm-project-agent-bridge/` | عيّنة محلية لحزمة الجسر، غير مثبتة. |
| `Plugin-Adapters/` | مصفوفة صلاحيات المضيف وعقد المحولات. |
| `Project-Documentation/` | الدعم والرخص والأدلة وتقارير المراحل. |
| `docs/User-Guides/` | دليلا الاستخدام للمبتدئين. |

## 5. افتح لوحة التحكم الطرفية

من المجلد الرئيسي للمشروع شغّل:

```powershell
TUI\AI-Project-Manager\AIPM.bat
```

يختار المشغّل إصدار PowerShell المتاح والمدعوم. لتشغيل الواجهة مباشرةً باستخدام PowerShell 7:

```powershell
pwsh -NoProfile -File TUI\AI-Project-Manager\Start-AIPM.ps1
```

ولتحديد Windows PowerShell 5.1 صراحةً:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File TUI\AI-Project-Manager\Start-AIPM.ps1
```

اللوحة للقراءة فقط. تعرض المشاريع والمهام ومعلومات المراحل وأدلة الاختبار وعمليات التسليم والمهارات والمطالبات والإعدادات. لا تنشئ مهامًا ولا تعدّلها.

## 6. تنقّل بين الشاشات

- اضغط **السهم لأعلى** أو **السهم لأسفل** لتغيير الخيار المحدد.
- اضغط **Enter** لفتح الخيار.
- اكتب رقم الخيار الظاهر لاختياره مباشرةً.
- اضغط **/** للبحث أو التصفية حيث تتوفر.
- اضغط **?** أو **F1** لعرض المساعدة.
- اضغط **Esc** للعودة إلى الشاشة السابقة.
- اضغط **Q** للخروج ثم أكّد الخروج عند ظهور الطلب.

يشير سهم ملون ونص أوضح إلى الخيار المحدد. لا يتم تظليل الشرح أسفل الخيارات. إذا لم تظهر الرموز بصورة صحيحة، استخدم إعداد ASCII الموضح في [دليل واجهة الطرفية](../../TUI/AI-Project-Manager/README.md).

## 7. اقرأ معلومات Core من PowerShell

شغّل الأوامر التالية من المجلد الرئيسي. تعرض النتائج بتنسيق JSON ليسهل قراءتها:

```powershell
python Core-Engine\aipm.py health
python Core-Engine\aipm.py catalog
python Core-Engine\aipm.py host-capabilities
python Core-Engine\aipm.py dashboard
```

يعرض `health` أن أداة Core بدأت. ويسرد `catalog` بيانات الفهرس، لكنه لا يثبت أن مضيفًا ثبّت مهارة أو شغّلها. ويعرض `host-capabilities` الصلاحيات المعلنة للمحولات. أما `dashboard` فيقرأ سجل المشاريع والحالة المضبوطين.

لقراءة سجل مشاريع محدد، أضف مساره. استبدل المسار ورقم المشروع في الأمثلة بالقيم التي زوّدك بها المسؤول:

```powershell
python Core-Engine\aipm.py list --registry "C:\path\to\project-registry.json"
python Core-Engine\aipm.py inspect --registry "C:\path\to\project-registry.json" --project-id "YOUR_PROJECT_ID"
python Core-Engine\aipm.py state-read --registry "C:\path\to\project-registry.json" --project-id "YOUR_PROJECT_ID"
```

إذا لم يكن لديك مسار السجل أو رقم المشروع، فلا تخمّن قيمة ولا تعدّل ملفات الفهرس المحمية. اطلب من مالك المشروع طريقة إعداد معتمدة. هذا الإصدار لا يوفّر أمر CLI عامًا لتسجيل مشروع جديد.

## 8. افهم المهارات والمطالبات وAgent Bridge

يمكن لمالك المشروع إضافة المهارات أو حذفها من `01-Skills-General/`، وإضافة المطالبات المستقلة أو حذفها من `02-Prompt-General/`. قبل التعديل:

1. أنشئ نسخة احتياطية أو احفظ التغيير في Git حتى تستطيع مراجعته أو التراجع عنه.
2. استخدم اسم المجلد التقني وملف `SKILL.md` بوضوح.
3. راجع المصدر وشروط الرخصة؛ فرخصة المشروع لا تلغي حقوق مؤلفي الطرف الثالث.
4. اتبع SemVer: ابدأ المهارة الجديدة أو المعاد ضبطها بالإصدار `1.0.0`، ثم حدّث الإصدار عند تطويرها.
5. حدّث الإصدار وسجل التغيير قبل تحديث بيانات الفهرس المحمي.
6. تحقّق من الفهرس وأعد بناء عينة الجسر المحلية بالأوامر التالية.

```powershell
python Maintenance-Tools\Invoke-Capability-Library.py validate
python Maintenance-Tools\Invoke-Capability-Library.py refresh-baseline --confirm-integrity-baseline-update --reason "Describe the authorized catalog change"
python Maintenance-Tools\Invoke-Capability-Library.py build-plugin
python Maintenance-Tools\Invoke-Capability-Library.py validate-plugin --output Plugins\aipm-project-agent-bridge
```

لا تشغّل `refresh-baseline` إلا بعد اعتماد التغيير وتحديث الإصدار وسجل التغيير. لا تعدّل `Capability-Library/Registry.json` أو سجل المصدر يدويًا. اترك الجسر محليًا وغير منشور ما لم يوافق المالك بصورة مستقلة على تثبيته أو نشره في مضيف مدعوم.

## 9. استخدم وكيل ذكاء اصطناعي بأمان

فتح المشروع في محرر يعمل بالذكاء الاصطناعي لا يثبّت الجسر ولا يبدأ وكيلًا ولا يمنح صلاحيات للملفات تلقائيًا. لا يحصل الوكيل المتوافق إلا على صلاحيات المضيف التي منحها المالك صراحةً. اقرأ [عقد محول المضيف](../../Plugin-Adapters/Host-Adapter-Contract.md) قبل تفعيل أي تكامل.

عند نقل العمل إلى جلسة أخرى، تعامل مع الملخصات المنسوخة كسياق لا كدليل. يجب أن تعيد الجلسة المستلمة قراءة الحالة والأدلة الحالية للمشروع. وتظل أي معلومة لا تدعمها أدلة قابلة للتحقق **مجهولة** أو **غير متحقق منها**.

## 10. أنشئ ملف مصدر وتحقق منه

لإنشاء أرشيف مصدر قابل لإعادة الإنتاج داخل `Releases/`:

```powershell
python Maintenance-Tools\New-Release-Package.py build
python Maintenance-Tools\New-Release-Package.py verify --archive Releases\AI-Project-Manager-v1.0.2.zip
```

تضم الحزمة مواد المشروع المخصصة للنشر ودليلي المبتدئين، وتستبعد قاعدة بيانات Git والملفات المؤقتة ومساحات الاختبار وخطط التنفيذ الداخلية. يتحقق الأمر من المجموع الاختباري وسجل بصمات الملفات. نجاح البناء المحلي لا يعني إنشاء إصدار على GitHub أو تثبيت الحزمة أو تفعيلها في مضيف.

## 11. حلول لمشكلات شائعة

| المشكلة | الحل |
| --- | --- |
| الأمر `python` غير معروف | ثبّت Python 3.10 أو أحدث، وافتح PowerShell من جديد، ثم نفّذ `python --version`. |
| الواجهة ترفض البدء | شغّلها من طرفية تفاعلية، لا من خلال أنبوب أو جلسة معاد توجيه مدخلاتها. |
| PowerShell 7 غير متاح | استخدم `AIPM.bat` أو أمر Windows PowerShell 5.1 أعلاه. |
| تظهر `NOT_REGISTERED` في لوحة المشاريع | لم يُعثر على سجل مشروع مضبوط. لا يتضمن هذا الإصدار أمر تسجيل عبر CLI؛ اطلب الطريقة المعتمدة من المالك. |
| تظهر المهارة بحالة غير متحقق منها | اعتبرها دليلًا غير مكتمل، لا تثبيتًا ناجحًا. راجع المصدر والفهرس المحلي. |
| يظهر رمز بصورة غير صحيحة | اضبط `AIPM_ICONS=ascii` أو راجع إعدادات الثيم في دليل TUI. |

## 12. قائمة تحقق للجلسة الأولى

1. اقرأ الرخصة وملف README.
2. تحقق من إصداري Python وPowerShell.
3. افتح الواجهة واستكشف لوحة القراءة فقط.
4. شغّل `health` و`catalog` و`host-capabilities`.
5. اقرأ مصفوفة الدعم وسجّل أي عنصر حالته `UNVERIFIED`.
6. لا تثبّت الجسر ولا تمنح وكيلًا صلاحية جديدة ما لم يعتمد المالك هذا التكامل المحدد.
7. لا تحفظ تغييرات المشروع إلا عبر مسار معتمد؛ واجهة TUI وأوامر CLI الموثقة في هذا الإصدار لا تعدّل حالة المشروع.
