# P02–P05 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close and verify the remaining P02–P05 Windows isolation, Core Engine/CLI, task lifecycle, and continuity gaps.

**Architecture:** P02 validates paths and effective access before creating state. P03 provides import-safe JSON CLI commands and a recoverable manifest/event commit protocol. P04 routes task mutations through `CoreEngine` and treats Markdown files as repairable projections of authoritative versioned task state. P05 observes Git and OS process identity without mutating project history, and performs only recoverable state-root quarantine/archive operations.

**Tech Stack:** Python 3 standard library, `unittest`, Windows filesystem/ACL APIs and Git CLI for live integration tests.

**Spec:** `docs/superpowers/specs/2026-10-15-p02-p05-hardening-design.md`

## Global Constraints

- All source edits, tests, fixtures, temporary repositories, and test-generated data must remain inside `D:\Test\02 │ Assistance Projects\AI Project Manager (AIPM)`.
- Tests use only the repository-local `.test-workspace`; they do not create or modify external managed projects.
- Do not edit the Universal AI Toolkit source, imported Skills, remote GitHub state, or excluded Skills.
- Do not push or publish changes.
- Preserve current CLI behavior, project-isolation rules, event history, evidence gates, and state-only rollback.
- Use Title Case for new human-facing labels, preserving technical identifiers and established filenames.

## Review Focus

- A junction in an intermediate component or an ACL denial must not allow partial or redirected state initialization; test in Task 1.
- Malformed registry/manifest JSON and unknown project IDs must produce stable CLI JSON errors without import-time execution; test in Task 2.
- A write failure between event and manifest persistence must not report success or strand an unreconciled revision; test/recover in Task 2.
- Tampered or missing task artifacts must not override authoritative task state or permit a false COMPLETE; test and repair in Task 3.
- Detached HEAD, PID reuse, process-query access denial, and archive name collisions must fail closed and preserve evidence; test in Task 4.
