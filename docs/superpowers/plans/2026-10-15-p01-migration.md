# P01 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish the new AIPM Git baseline and safely migrate the approved 17-skill subset.

**Architecture:** A repository-owned migration utility stages data outside the checkout, verifies source inventories and hashes, applies only the owner-approved exclusions and catalog removal, and verifies the installed result.

**Tech Stack:** Git, Python 3 standard library, PowerShell for invocation.

**Spec:** `docs/superpowers/specs/2026-10-15-p01-migration-design.md`

## Global Constraints

- Do not write to the Universal AI ToolKit source or push to GitHub.
- Use Apache-2.0 only for newly authored AIPM files; retain imported notices.
- Migrate 17 approved Skills, not 19; preserve 16 byte-identically.
- Treat `project-orchestrator` as the sole controlled derivative and remove all `msg-*` references.
- Human-facing names use Title Case unless technical conventions require otherwise.

## Review Focus

- Existing destination content must never be overwritten by a conflicting migration.
- A source link, case collision, or unexpected Skill directory must stop migration.
- Excluded Skills and Personal Skills must not enter the repository.
- The derivative must not leave a hidden Personal Skill reference in a changelog.
- Root Apache-2.0 must not be represented as relicensing imported content.
