### AIPM Universal Activation And Execution Prompt

`AIPM-Universal-Activation-Prompt.md`

**Description:** A bilingual activation and execution prompt that makes AIPM's Project Manager, Task Scope Contract, and Resource Optimization skills the task's management layer, then applies lifecycle, capability selection, resource, continuity, and evidence gates.

**When to Use:** Use it to start a task under AIPM governance and keep its required management policies active through verified delivery.

**How to Use:** Example: “Use the [AIPM Universal Activation & Execution Prompt](../../02-Prompt-General/AIPM-Universal-Activation-Prompt.md), then follow these project-specific instructions: …”

### Autonomous Task Execution

`Autonomous-Task-Execution.md`

**Description:** A bilingual English and Arabic instruction set for carrying a task from start through verified completion, making routine decisions independently, preserving constraints, and reporting evidence accurately.

**When to Use:** Use it when you want an AI agent to work through an authorized task end to end, avoid unnecessary approval interruptions, and provide a concise evidence-based completion report.

**How to Use:** Example: “Follow the [Autonomous Task Execution Prompt](../../02-Prompt-General/Autonomous-Task-Execution.md) for this task, within the project rules and permissions.”

**Source:** [Read The Full Prompt](../../02-Prompt-General/Autonomous-Task-Execution.md)
