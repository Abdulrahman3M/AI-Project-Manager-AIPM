# AIPM Beginner Guides

Choose a language for a step-by-step tour of AI Project Manager, from downloading the project through daily read-only use, capability maintenance, and safe updates.

| Language | Guide |
| --- | --- |
| English | [AI Project Manager Beginner Guide](Beginner-Guide.en.md) |
| العربية | [دليل المبتدئين إلى مدير المشاريع بالذكاء الاصطناعي](دليل-المبتدئين.ar.md) |

Both guides describe the same product boundaries. The TUI and Core CLI can update AIPM-owned project/task state through validated operations, but they do not edit project source files or execute project tests. A package manifest does not install an AI agent or grant access to project files.
