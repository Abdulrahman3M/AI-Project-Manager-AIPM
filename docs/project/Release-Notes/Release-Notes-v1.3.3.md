# AI Project Manager v1.3.3

Development update; not published as a GitHub Release.

## Changes

- Added search exclusively to **View Attached Task Files**. Search accepts a complete or partial filename or task-relative path and reports exact-match availability alongside the matching file inventory.
- Added an empty-query reset to restore the full attachment list, and updated the architecture and English/Arabic beginner guides.
- Added scripted UI regression coverage for an exact match, a missing file, and clearing the search.

## Scope And Verification

- Platform and PowerShell TUI versions are synchronized at `1.3.3`.
- No Skills or Prompts changed; Plugin archives were not rebuilt.
- No source ZIP, GitHub Release, or tag was created for this development update.
