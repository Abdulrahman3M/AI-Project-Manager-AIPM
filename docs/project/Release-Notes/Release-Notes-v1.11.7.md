# AIPM v1.11.7 Repository Update

This local, unpublished update strengthens the Golden Triangle record checks: retries require a changed documented hypothesis or evidence, telemetry is marked measured only when the caller asserts that the measurement was verified, and build staging rejects linked path components. Shared Project State Manager operational guides use PowerShell entry points, including a validator wrapper.

These checks do not intercept host actions or independently authenticate a caller's evidence. Actual host activation remains unverified. Platform and TUI versions are synchronized; see the preceding [v1.11.6 notes](Release-Notes-v1.11.6.md).

Bridge replacement also refuses legacy guidance on a package that already contains Project Manager; pre-manager packages retain a verified upgrade path.
