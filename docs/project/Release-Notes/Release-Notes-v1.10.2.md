# AIPM v1.10.2 Release Notes

## PowerShell Operator Guides

Added dedicated operator manuals in English and Arabic for the PowerShell TUI. They explain requirements, launch options, keyboard navigation, project registration and migration, task evidence, Git/FIRG workflows, recovery, strengths, and operational limits. The guides are linked from the documentation indexes.

The local `Shared-Project-State-Manager/` runtime data directory is now ignored by Git so caches, logs, locks, and test workspaces are not mistaken for product source or staged accidentally. Existing contents were preserved.

Platform and TUI versions are synchronized at `1.10.2`. This is a local repository update and is not a published GitHub Release.
