# AIPM v1.6.13 Release Notes

## Web Design Engineering Skill

This repository update adds `web-design-engineering` version `1.0.2`, an AIPM-owned General Skill for production web interfaces. It combines subject-specific direction with practical engineering: reusable tokens and contracts, responsive and RTL guidance, accessibility and interaction checks, reference-fidelity boundaries, rendered verification gates, examples, templates, and standard-library helper scripts.

The Skill's research synthesis attributes public sources including Impeccable, Anthropic Frontend Design, UI/UX Pro Max, Taste Skill v2, and Emil Design Engineering. It distills principles only; no third-party Skill content, datasets, code, assets, or paid material is packaged.

## Distribution

Version `1.6.13` is an unpublished repository update. The protected capability registry now records 13 General Skills. Its helper tests explicitly suppress generated Python bytecode so local test caches cannot cause catalog drift. The local legacy Bridge and all three local multi-host archives are rebuilt and validated against that registry, including their inventories and SHA-256 sidecars. They are not installed in ChatGPT/Codex, Claude Code, or Google Antigravity, and no GitHub Release or tag was created.
