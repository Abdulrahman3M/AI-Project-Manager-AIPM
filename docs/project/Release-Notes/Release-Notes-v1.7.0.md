## Professional Word Designer

- The AIPM-distributed `professional-word-designer` advances to `1.1.0` with enterprise visual-design guidance, 36 original reusable template patterns, and a research-attributed tools landscape.
- Arabic-first and Arabic/English bilingual Word output now has a six-layer RTL contract covering Word settings, default styles, sections, tables, paragraphs and runs. The bundled baseline builder and auditor implement and inspect these layers.
- The Skill distinguishes prose quotations from literal inline code. It documents `«…»` for Arabic prose when permitted by house style, and a selectable `Code Inline` style for literal examples such as `هذا النص كمثال`.
