# AIPM v1.5.4 Release Notes

## Accept Agent-Created Task Folders

- **Fix:** **Add Existing Work Folder** (TUI and Core `task-import-work-folder`) now accepts an existing folder inside `Shared-Project-State-Manager`, such as a task folder an AI Agent created under `Tasks/`. Only the state root itself and its `Tasks` container are rejected. Files stay in place.

## Distribution

Version `1.5.4` is an unpublished repository update. No Skill or Prompt content changed, so Plugin versions remain unchanged.
