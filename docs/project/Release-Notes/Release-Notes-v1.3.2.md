# AI Project Manager v1.3.2

Development update; not published as a GitHub Release.

## Changes

- Long read-only TUI pages, including task attachment inventories, now paginate according to terminal height.
- Use Up/Down or PageUp/PageDown to move between pages; the page counter makes remaining entries visible and Enter/Esc return to the prior screen.
- Added regression coverage for reaching late entries in a long list on a short terminal.

## Scope And Verification

- Platform and PowerShell TUI versions are synchronized at `1.3.2`.
- No Skills or Prompts changed; Plugin archives were not rebuilt.
- No GitHub Release or tag was created.
