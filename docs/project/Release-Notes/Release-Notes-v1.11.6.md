# AIPM v1.11.6 Repository Update

This local, unpublished update adds resource-budget revision checks that preserve required verification and previously reported observations. It follows the [v1.11.5 Golden Triangle update](Release-Notes-v1.11.5.md); platform and TUI versions remain synchronized.

Budget checks evaluate supplied records. They do not measure a provider's quota, enforce host behavior, or waive mandatory tests. Host runtime enforcement remains unverified until tested on the actual host. No release or Plugin is published or installed by this repository update.
