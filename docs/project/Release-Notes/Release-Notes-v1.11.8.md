# AIPM v1.11.8 Repository Update

This local, unpublished update permits a bounded retry when recorded evidence changes even if the hypothesis stays the same. It also rejects legacy bridge guidance on a package that already contains Project Manager while preserving a verified pre-manager upgrade path.

The record checks do not independently verify caller-supplied evidence or enforce host invocation. Platform and TUI versions remain synchronized; host runtime enforcement remains unverified. See the preceding [v1.11.7 notes](Release-Notes-v1.11.7.md).

Git attributes preserve the exact bytes of Skill masters and generated bridge files, protecting their recorded checksums from automatic line-ending conversion.
