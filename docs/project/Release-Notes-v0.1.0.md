# Release Notes v0.1.0

This is the initial local AIPM platform baseline after P06. It is repository metadata, not a public release.

## Included

- Capability registry for 17 approved General Skills, Skill-owned Prompt relationships, and one standalone Prompt.
- Source revision and SHA-256 provenance ledger, with the imported Personal Use License and per-Skill notices preserved.
- Validation, version-policy, atomic baseline, and General-only Plugin generation tools.
- A verified local Plugin sample that is neither published nor installed.
