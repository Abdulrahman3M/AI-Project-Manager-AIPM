# Release Package v5

A complete release contains only requested user deliverables plus the audit companions required by the Document Contract.

For standard work: editable DOCX, optional requested PDF/HTML companion, and release report.
For research-heavy work: optionally include reproducibility artifacts.
For Chapter Package Mode: include Index DOCX, all chapter DOCX files, chapter manifest, package QA and requested companions.

Never mark the package PASS while blocking research, structural, example-coverage or render failures remain.

## Requirements and examples

- REQ-PK-01 — package contents match the Document Contract.
- REQ-PK-02 — every claimed artifact exists and opens/validates where tooling allows.
- REQ-PK-03 — verified/unverified status is explicit.
- REQ-PK-04 — Chapter Package Mode includes Index + manifest + all declared chapter files.
