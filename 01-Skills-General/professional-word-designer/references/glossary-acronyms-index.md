# Glossary, Acronyms and Subject Index

## Glossary

Include terms that readers genuinely need to interpret the document. Definitions must match usage in the text.

## Acronyms

Introduce an acronym on first substantive use unless the target convention says otherwise. Maintain one canonical expansion.

## Subject index

For books, theses or very long reports, create Word index entries/fields when the tooling can verify them. Otherwise provide a clearly labeled static index only when requested.

## Requirements and examples

- REQ-GI-01 — glossary terms are used in the document and defined consistently.
- REQ-GI-02 — acronyms have one canonical expansion.
- REQ-GI-03 — unused glossary/index filler is prohibited.
- REQ-GI-04 — dynamic Word index behavior is claimed only when fields are actually present and refreshed/verified.
