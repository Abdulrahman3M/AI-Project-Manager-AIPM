# Template Fidelity, Reviewer Workflow and Consistency

## Template fidelity

When given DOCX/DOTX, inspect page size, margins, sections, styles, numbering, headers/footers, fields, tables, language/direction, theme and protected content. Record an inventory before drafting. Preserve the template's structure and update only instructed components.

**Example.** A university template uses Roman numerals for front matter and Arabic numbering for the body. Preserve the section transition and verify both first pages.

## Reviewer workflow

Assign each comment a stable ID; track request, response, change/location, evidence or rationale, status and unresolved dependency. Preserve the original. Use native comments/Track Changes only if tools truly write and verify those structures.

**Example.** R-07 asks to clarify a limitation. The response matrix points to Discussion paragraph 4 and marks resolved after inspection. A typed before/after report is not native Track Changes.

## Consistency and citation-safe originality

Check terminology, names, dates, units, definitions, repeated arguments, contradictions, figures and tables across the whole work. Compare paraphrases with consulted sources for unusually close wording and rewrite or strengthen attribution. This is editorial review, not a plagiarism detector.

**Example.** Two chapters define adherence differently. Harmonize the term or explicitly distinguish contexts.

## Tables, figures and journal submission

Use tables for comparable attributes and charts only for verified measurements. Dense wide tables may use landscape sections; long tables need repeated headers and tested continuation. Submission checks must use actual current journal instructions.

**Example.** Move a seven-column table to a landscape section only when needed, then verify repeated header, source note and reading order after rendering.
