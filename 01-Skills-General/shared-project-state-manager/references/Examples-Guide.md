# Examples Guide

The `examples/` directory intentionally contains many worked situations so an AI agent can infer the expected state/handoff form under varied conditions.

## How an Agent Should Use Examples

1. Read `examples/README.md` and select the nearest scenario(s).
2. Copy the structure and decision pattern, not project-specific facts.
3. Replace IDs, paths, branches, agents, tests, and status with observed reality.
4. If an example conflicts with the active project or repository reality, ignore the conflicting detail.
5. Never mark a check PASS merely because an example says PASS.
6. Combine patterns when a real case spans multiple examples.

Examples are teaching material, not a hidden specification. `SKILL.md`, project governance, and verified reality remain authoritative.
