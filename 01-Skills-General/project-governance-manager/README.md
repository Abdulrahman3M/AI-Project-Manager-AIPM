# Project Governance Manager

A reusable governance Skill for creating, merging, auditing, and maintaining `AGENTS.md` and related project-rule systems.

It is designed to distinguish:

- universal project-governance rules;
- conditional rules that apply only when a project uses a feature;
- project-specific rules that must remain scoped;
- technical conventions that must not be renamed or generalized away;
- historical/superseded rules that should not compete with current authority.

## Main capabilities

- Merge multiple governance documents without silently losing intent.
- Extract common rules and generalize unique rules when safe.
- Resolve conflicts by scope, authority, recency, and explicit owner decisions.
- Create an adaptable `AGENTS.md` baseline.
- Audit governance for duplication, contradictions, stale paths, missing safeguards, and competing sources of truth.
- Distill recurring owner instructions and solved mistakes into permanent rules.
- Trace generalized rules back to their source families with a reviewable rule-source matrix.

Read `SKILL.md` for the authoritative workflow.
