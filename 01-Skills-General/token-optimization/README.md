# Token Optimization

Reusable, independent cross-stage efficiency guidance for analysis, MD handoff creation and task implementation. Reduce repeated context retrieval, lengthy duplicate responses, unnecessary multi-agent fan-out, and blind retries while retaining requirements, quality and tests.

Default to one agent. Require explicit owner approval for multi-agent teams; never save tokens by reducing completeness or tests.

A companion to `deep-brainstorming`, `create-strict-implementation-handoff`, Project Orchestrator and execution Skills. It never replaces any of them and cannot guarantee a quota reduction.
