# Example: RTL And Localization Case

An Arabic account settings screen uses logical CSS properties (`margin-inline`, `padding-inline`, `inset-inline-start`) rather than left/right offsets. Navigation order follows the document direction; an icon that indicates “next” mirrors only when its meaning is directional. Product names, email addresses, code, and measurements remain isolated where necessary. Test long German labels, Arabic headings, and mixed Arabic-English validation text before claiming localization support.
