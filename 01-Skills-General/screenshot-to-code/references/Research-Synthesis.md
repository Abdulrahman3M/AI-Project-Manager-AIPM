## Synthesis Boundaries

Implement code directly when requested. A prompt-only response does not fulfill implementation. Keep text and controls semantic; a screenshot bitmap is not a successful reconstruction. Do not invent font identity, motion timing, hidden states or responsive behavior from static evidence. Use originals before generation, preserve Arabic shaping and mixed-direction content, compare regions independently, and disclose residuals after bounded repairs.

A helper regression or controlled browser fixture does not prove universal reconstruction quality. Use the held-out behavioral scenarios for that separate evaluation. Source licenses require a fresh check before any future copying; README license assertions are not a license audit.
