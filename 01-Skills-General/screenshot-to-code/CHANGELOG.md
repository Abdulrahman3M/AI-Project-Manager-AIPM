# Change Log

## [1.1.0] — 2026-10-26

- Added screenshot-only default and an explicit opt-in flow for authorized, visible client-side browser inspection.
- Defined page scope, browser identity checks, privacy boundaries, provenance reporting and screenshot-only fallback.
- Added practical cases for viewport scale, responsive references, Arabic RTL, missing fonts, unknown states and cropped pages.
- Prohibited references to undefined CSS custom properties.

## [1.0.0] — 2026-10-26

- Introduced the original AIPM Screenshot To Code Skill for direct screenshot-driven frontend reconstruction.
- Added evidence-calibrated measurements, font and asset provenance, existing-project boundaries, RTL, responsive inference and regional visual repair gates.
- Added original Pillow diagnostic tools and regression tests; distinguish numeric verification from unexecuted autonomous reconstruction evaluations.
