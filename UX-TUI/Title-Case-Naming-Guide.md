# Title Case Naming Guide

New English human-facing screen titles, actions, labels, help, descriptions, errors, and Markdown headings use Title Case. Preserve technical names and identifiers such as `AI`, `AIPM`, `TUI`, `CLI`, `API`, `JSON`, `SHA-256`, `ANSI`, `ASCII`, machine states, commands, filenames, keys, and Skill slugs. Never alter imported Skill content or user-provided dynamic text to satisfy the display style.
