# Citation Style Engine

The chosen citation system is part of the Document Contract.

## First-class styles

APA 7, IEEE, Vancouver, Chicago Notes/Bibliography, Chicago Author-Date, MLA 9 and Harvard-style author-date. Other styles may be supplied by a verified CSL/Zotero workflow.

## Rules

- Never mix styles silently.
- Citation placement, author truncation, date, punctuation, title case, DOI/URL and bibliography ordering follow the selected style.
- Use real Word footnotes/endnotes for note-based styles when supported.
- If a host cannot create native notes, disclose the limitation rather than simulating them as ordinary superscript.
- When Zotero/CSL is available, prefer the real processor; otherwise use deterministic local formatting and identify it as static.

## Requirements and examples

- REQ-CS-01 — one style is selected and recorded.
- REQ-CS-02 — in-text/notes and bibliography use the same style contract.
- REQ-CS-03 — note-based styles use real notes when claimed.
- REQ-CS-04 — unsupported live citation-manager behavior is never fabricated.
