# Equations, Glossaries, Acronyms and Indexes

## Equations

Prefer actual editable Word equations (OMML) when the authoring tools support them. Give equations stable IDs, use genuine cross-reference fields where available, and define symbols near first use or in a notation list. If unsupported, label the alternative honestly, such as accessible equation image or a separate MathML-capable companion.

**Example.** Define every variable below its equation. A screenshot is not an editable Word equation.

## Glossary and acronyms

Track term, definition, first-use location, source when specialized, capitalization/plural and language equivalents. Expand acronyms at first use unless audience/style guidance differs. Generate a glossary only when useful.

**Example.** Expand “World Health Organization (WHO)” once and use WHO consistently; do not list acronyms absent from the document.

## Index

For long works, identify index terms and locations. Generate a real Word index field only when creation and refresh are supported; otherwise provide a labeled static topic index and disclose it will not update automatically.

**Example.** A static index lists “Evidence, 14–18” only after final pagination is checked; regenerate after any layout change.
