# Research Reproducibility Package

For research-heavy work, optionally deliver or retain a machine-readable audit package beside the DOCX.

Recommended contents:
- document-contract.json
- research-plan.json
- source-ledger.json
- claim-evidence.json
- literature-synthesis.json when relevant
- visual-register.json
- citation-records.json
- chapter-manifest.json for large-document mode
- research-qa.json
- release-report.md

Do not include copyrighted full-text sources unless redistribution is permitted.

## Requirements and examples

- REQ-RP-01 — audit artifacts correspond to the delivered document version.
- REQ-RP-02 — source IDs remain stable across artifacts.
- REQ-RP-03 — protected/copyrighted source content is not repackaged without permission.
- REQ-RP-04 — release report states what was and was not verified.
