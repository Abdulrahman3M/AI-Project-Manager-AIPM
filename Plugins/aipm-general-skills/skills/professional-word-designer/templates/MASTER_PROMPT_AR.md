# البرومبت المستقل — Professional Word Designer v5

أنشئ **[الموضوع]** في صورة منشور Microsoft Word احترافي وقابل للتعديل للجمهور **[الجمهور]** باللغة **[اللغة/المحلية]** وبنوع مستند **[نوع المستند]** ونمط مراجع **[Citation Style]** وبالتصميم أو القالب **[Profile/Template]**.

ابدأ إلزاميًا بـ **Document Contract** ثم **Research Plan**. ابحث باستخدام الأدوات المتاحة فعليًا، وصنّف جودة المصادر، وأنشئ **Source Ledger** موثقًا، ثم أعطِ الادعاءات المهمة IDs ثابتة داخل **Claim–Evidence Matrix** واربط كل ادعاء بما يثبته تحديدًا. احتفظ بالتعارضات والثغرات ولا تخفها. بعد ذلك اختر **Academic Document Mode** الصحيح وابنِ الهيكل المناسب قبل كتابة النص النهائي.

استخدم نمط المراجع المطلوب بصورة متسقة مثل APA 7 أو IEEE أو Vancouver أو Chicago أو MLA أو Harvard. لا تختلق مؤلفًا أو DOI أو URL أو رقم صفحة أو اقتباسًا أو إحصائية أو ترخيصًا أو جهة أو انتسابًا أو تمويلًا أو موافقة أخلاقية. في Literature Review قم بالتركيب والمقارنة بين الأدلة، لا بتلخيص كل مصدر منفردًا بالتتابع.

أضف Abstract/Keywords/Front Matter، Glossary/Acronyms، المعادلات الأصلية في Word، الجداول والأشكال والفهرس الموضوعي فقط عندما يقتضي نوع المستند ذلك. طبّق نظام العناصر البصرية: لا تضف عنصرًا بصريًا بلا فائدة تعليمية حقيقية، وسجّل المصدر/الترخيص/الوصف البديل/التعليق/الوحدات والبيانات عند الحاجة.

استخدم Word الحقيقي: Heading styles، وحقول TOC/PAGE/STYLEREF/SEQ/REF عند الحاجة، وFootnotes/Endnotes الحقيقية عندما تدّعي وجودها وتدعمها الأداة، وجداول وصناديق قابلة للتعديل، واتجاه RTL/LTR صحيح، وSection Breaks سليمة. وجود Field في OOXML لا يعني أن نتيجته الظاهرة تم تحديثها.

**قاعدة الأبحاث الضخمة:** إذا كان البحث **100 صفحة أو أكثر** أو متوقعًا أن يصل لذلك، فالوضع الافتراضي هو **Chapter Package Mode** ما لم يطلب المالك ملف DOCX واحدًا صراحةً. قسّم العمل إلى ملفات Word للفصول، وأنشئ `chapter-manifest.json` وملف `00-Index.docx`. عند دعم ذلك، يجب أن تكون أسماء الفصول داخل ملف الـIndex روابط خارجية نسبية تفتح ملف Word الخاص بكل فصل مباشرة.

طبّق نظام الأمثلة الإلزامي: كل Requirement في v5 له مثال معياري يوضح السيناريو والتنفيذ الصحيح والخاطئ ودليل القبول؛ لا تترك للـAI Agent حرية اختراع نمط مخالف. نفّذ فحوص example coverage والمراجع والادعاءات والفصول وResearch QA، ثم DOCX QA وتحديث الحقول إن توفرت أداة قادرة، ثم Render لجميع الصفحات وفحصها وإصلاح أي خلل.

سلّم فقط الملفات المطلوبة وملفات التدقيق/إعادة الإنتاج اللازمة. صرّح بدقة بما هو PASS أو FAIL أو UNVERIFIED. لا تدّع Zotero/CSL حيًا أو Track Changes أو Comments أصلية أو مخططات Office قابلة للتحرير أو تحديث Fields أو نتيجة Plagiarism/AI Detector أو قبول نشر إلا إذا تم تنفيذ ذلك فعليًا والتحقق منه.
