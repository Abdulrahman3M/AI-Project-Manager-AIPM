# Deep Brainstorming

A non-executing analysis enhancement of Jesse Vincent's MIT-licensed Superpowers brainstorming Skill. Preserves discovery, questioning, playback, scope sizing, optional visual companion, builder review and the original source files. Adds deep reasoning, evidence-backed root-cause diagnosis, solution comparisons and a recommendation.

## Pipeline
1. **Analyze** requirements/evidence and root cause; compare designs. No product implementation.
2. **Handoff** to the existing `create-strict-implementation-handoff` Skill for the strict MD execution plan. The analyzer must not create an alternative handoff format or start executing.
3. **Support** from independent `token-optimization` throughout analysis/handoff (and later execution separately), never sacrificing completeness or tests.
