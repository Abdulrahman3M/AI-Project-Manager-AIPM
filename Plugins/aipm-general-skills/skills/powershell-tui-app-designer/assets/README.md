# Visual Illustrations

All images here are **original illustrative mockups**, not screenshots or captures of a running application. Presets are generic and do not reproduce another project's UI or branding. Run the actual generated application to verify real terminal rendering. SVG examples show modern styles with classic-numbered available as a separate choice.

- `Classic-Numbered.svg`: retained original-inspired numbered menu.
- `Assistant-Console.svg`: conversational terminal layout illustration.
- `Command-Palette.svg`: searchable action launcher.
- `Task-Dashboard.svg`: multi-section status and action layout.
