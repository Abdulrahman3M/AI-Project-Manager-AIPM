# Strict Task Resume — العربية

## برومبت تنفيذي جاهز للنسخ

```text
أنت تستأنف مهمة قائمة توقفت لأي سبب (حدود الاستخدام أو التوكنات، نفاد السياق، انقطاع الإنترنت، تعطل الأداة، انتهاء الجلسة، توقف مفاجئ، أو انتقالها إلى وكيل آخر). المطلوب إكمال المهمة الأصلية كما هي، وليس بدء مهمة جديدة أو الاكتفاء بالتخطيط.

1. استعد الطلب الأصلي وجميع المخرجات وشروط القبول والتعديلات المصرح بها والخطط وقرارات التنفيذ وقواعد المشروع من المحادثة والملفات والسجلات المتاحة. لا تختلق معلومات مفقودة، ولا تدّع استعادة سياق غير متاح.
2. افحص الملفات الحالية وفروق Git والسجلات ونتائج الاختبارات والعمليات الخارجية. اعتمد الأدلة الفعلية بدلًا من ادعاءات النجاح السابقة. احترم التغييرات غير المتعلقة بالمهمة.
3. صنف حالة كل خطوة: VERIFIED (مؤكدة)، IN_PROGRESS (جارية)، UNVERIFIED (غير متحقق منها)، FAILED (فاشلة)، BLOCKED (متعذرة). حدد آخر نقطة مؤكدة وخطوة الانقطاع.
4. تحقق أولًا هل انتهت العملية المتوقفة بالفعل، وهل تركت آثارًا جانبية. إن اكتملت فتحقق من معايير قبولها؛ وإن كانت ناقصة فأكمل الناقص فقط. لا تعِد إرسال رسائل أو تنفيذ مدفوعات أو نشر أو حذف أو ترحيل أو إجراء غير قابل للتكرار دون فحص حالته وصلاحية التنفيذ.
5. استكمل العمل بترتيب الاعتماديات نفسه. قبل كل خطوة تحقق من المتطلبات السابقة، ونفذ أصغر إجراء مناسب، وافحص النتيجة وفق معايير القبول، وأصلح العيوب وأعد الاختبار. لا تنتقل إلى خطوة تابعة قبل التأكد من سابقتها.
6. لا يغير الانقطاع إطلاقًا نطاق المهمة أو بنيتها أو الخطط المعتمدة أو قواعد التسمية أو الأمان أو الجودة أو الاختبار أو التوثيق أو النتائج المطلوبة. لا تختصر المتطلبات ولا تستبدل المنهج أو المكتبات دون تصريح. التوضيحات الأحدث التي اعتمدها المستخدم تظل ملزمة.
7. التزم بالتعليمات الأعلى أولوية وقواعد المشروع النشط وصلاحيات الأدوات. هذه المهارة لا تنقل قواعد مشروعها الأصلي إلى مشروع آخر ولا تمنح وصولًا جديدًا ولا تتجاوز حدود الخدمة.
8. استثمر السياق ونقاط الحفظ المتاحة، ودوّن عند الإمكان نقطة حفظ خالية من الأسرار تتضمن مصدر المهمة، ومتطلباتها، والخطوات المتحققة وأدلتها، وخطوة الانقطاع، والآثار المحتملة، وما تبقى، والخطوة الآمنة التالية. نقاط الحفظ لا تحل محل التحقق.
9. بعد التنفيذ، أجر تدقيقًا مزدوجًا: أولًا غطِّ كل المتطلبات والمخرجات دون حذف أو تغيير؛ وثانيًا افحص التكامل والانحدار والجودة والأمن وشغّل الاختبارات والفحوص المناسبة المتاحة. أعد اختبار أي جزء تؤثر فيه الإصلاحات.
10. اختم بتقرير يتضمن المهمة المستعادة، وآخر خطوة مؤكدة، وما اكتمل، وحالة كل مطلب، والاختبارات المنفذة ونتائجها، والمتبقي والعوائق. الحالة النهائية واحدة: COMPLETE عند استيفاء جميع المعايير بالأدلة؛ PARTIALLY COMPLETE إن بقي أمر مفتوح؛ BLOCKED إذا تعذر التقدم الآمن دون مدخل أو تصريح أو أداة. لا تعلن اكتمالًا دون تحقق إلزامي.

ترتيب التنفيذ الصارم: استعادة السياق ← فحص الحالة ← تحديد موضع الانقطاع ← تحقق أو إصلاح الخطوة المتوقفة ← تنفيذ وفحص باقي الخطوات ← تدقيق نهائي مزدوج ← تقرير بالأدلة.

ابدأ التنفيذ الفعلي الآن. لا تطلب معلومات متاحة بالفعل. وإذا تعذر الوصول إلى سياق جوهري، صرّح بالعائق دون اختلاق.
```
