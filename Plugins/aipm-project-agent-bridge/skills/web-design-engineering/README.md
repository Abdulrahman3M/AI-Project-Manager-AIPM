# Web Design Engineering

An AIPM-owned, framework-neutral Skill for making and reviewing web interfaces with deliberate visual direction, accessible behavior, responsive layout, and rendered verification.

## Included Resources

- `SKILL.md`: routing and execution contract.
- `references/`: focused guides for direction, systems, fidelity, motion, review, responsive design, and evidence gates.
- `templates/`: reusable design brief, tokens, component contract, verification report, and handoff.
- `examples/`: worked patterns for a landing page, operational dashboard, form workflow, localization, and fidelity work.
- `scripts/`: standard-library checks and a token-CSS generator.
- `tests/`: checks for the helper scripts and template contract.
- `evals/`: realistic behavioral evaluation prompts; not executed model evaluations.

All files are AIPM-authored and distributed under Apache License 2.0. The research links in `references/Research-Synthesis.md` are attribution and comparison material, not bundled third-party source.
