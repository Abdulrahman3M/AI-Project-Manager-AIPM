# Reference Fidelity

When a screenshot, Figma frame, or live reference is supplied, fidelity means the requested observable outcome—not unlicensed asset extraction or blind pixel imitation.

1. Inventory viewport, hierarchy, grid, typography roles, spacing rhythm, color roles, imagery ownership, states, and interactions.
2. List unknowns separately from observations. Do not infer mobile behavior, hidden menus, data, or animation from one static image.
3. Match the target with semantic, maintainable structure in the repository's stack. Prefer local assets and existing primitives.
4. Compare current renders at the target viewport plus each requested responsive state. Log meaningful deltas: structure, text metrics, crop, contrast, overflow, control state, and behavior.
5. Declare a comparison `UNVERIFIED` when no legal visual reference, target viewport, runtime, or browser capture is available.

Never present an approximation as pixel-perfect unless measurement and comparison were actually performed.
