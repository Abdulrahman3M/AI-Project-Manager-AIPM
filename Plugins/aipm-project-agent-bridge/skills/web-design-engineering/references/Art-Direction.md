# Art Direction

## Decide Before Styling

Write a one-sentence thesis tying the product's subject, audience, and screen job to a visual decision. Then define one signature: an information shape, material, image treatment, type behavior, or interaction that is meaningful to that subject. The signature is not a random gradient, animation, or trendy style label.

Use real content as early as possible. Placeholder copy hides hierarchy problems and produces false confidence. If content is unavailable, label assumptions and use plausible, specific text rather than lorem ipsum.

## Compact Direction Card

| Field | Decision |
| --- | --- |
| Audience and moment | Who is here, what are they trying to decide or do? |
| Primary action | One observable result, not a vague aspiration |
| Hierarchy | What earns the first viewport, what may wait? |
| Palette | 4–6 role-based colors with contrast duties |
| Typography | Display, body, utility roles and why they fit |
| Layout | Alignment, density, rhythm, and responsive behavior |
| Signature | One domain-derived memorable element |
| Restraint | What familiar decoration is intentionally excluded? |

## Critique Questions

- Could the same direction describe a competitor or unrelated product? If yes, make the thesis more concrete.
- Does the first viewport establish identity and the page's primary job?
- Is the most expressive element helping comprehension or just consuming attention?
- Does every visual separator encode hierarchy, grouping, sequence, or state?
- Would the result remain coherent if the accent color or hero image failed to load?
