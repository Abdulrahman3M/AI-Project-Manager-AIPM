# Example: Community Workshop Landing Page

**Thesis:** The first screen feels like a printed workshop schedule pinned in a bright studio, making upcoming sessions and registration immediately legible.

- **Audience:** Local makers deciding whether to attend a class.
- **Primary job:** Select a workshop and reserve a place.
- **Hierarchy:** Upcoming workshop first; outcomes and instructor proof second; FAQ last.
- **Signature:** A responsive timetable whose colored blocks reflect real workshop durations, not decorative bento cards.
- **Restraint:** No generic dashboard cards, counter animations, or stock tool imagery.
- **Responsive plan:** Timetable changes to a chronological list with date headers; full workshop names never truncate.
- **Evidence:** Check 320px, 768px, and 1440px; keyboard-select a workshop; test sold-out, waitlist, and long instructor names.
