The example is evidence of intended execution: an agent must not improvise a conflicting behavior merely because an abstract rule seems open to interpretation.

Every entry contains a scenario, correct path, prohibited path and acceptance evidence. Run `python scripts/validate_example_coverage.py` to enforce 100% coverage.
