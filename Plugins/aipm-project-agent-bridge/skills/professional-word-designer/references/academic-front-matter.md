# Academic Front Matter Engine

Generate front matter conditionally from document type and submission rules.

Potential components: title page, author information supplied by owner, affiliation supplied by owner, abstract, structured abstract, keywords, highlights, table of contents, list of figures, list of tables, abbreviations, nomenclature, acknowledgments, declarations/conflicts, funding statement, ethics statement and document metadata.

Do not invent author names, affiliations, funding, approvals, conflicts, ORCID IDs or ethics statements.

## Requirements and examples

- REQ-AF-01 — front matter is type/journal driven.
- REQ-AF-02 — abstract accurately reflects the final document.
- REQ-AF-03 — keywords represent actual searchable concepts.
- REQ-AF-04 — identity/compliance statements use only verified owner-supplied facts.
