# Native Mathematics and Equations

Prefer native editable Word mathematics (OMML) when the host can generate and verify it. Equations may be inline or display equations and may have stable numbering and cross-references.

## Rules

- Preserve mathematical semantics, superscripts, subscripts, matrices, fractions and symbols.
- Define variables on first use or in nomenclature when appropriate.
- Number only equations that need reference.
- Use real equation references/bookmarks when supported.
- Never replace important equations with screenshots merely for appearance.
- If OMML generation is unavailable, use a disclosed editable/plain fallback rather than claiming native math.

## Requirements and examples

- REQ-ME-01 — mathematical expressions remain semantically correct and editable where supported.
- REQ-ME-02 — symbols/variables are defined consistently.
- REQ-ME-03 — equation numbers and references are stable when used.
- REQ-ME-04 — raster math is a fallback, not the default.
