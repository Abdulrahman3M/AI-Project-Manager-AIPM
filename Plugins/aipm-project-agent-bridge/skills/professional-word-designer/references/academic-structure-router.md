# Academic Structure Router

Use the Document Contract and document mode to produce the outline.

## Routing logic

- Empirical research: Abstract → Introduction → Methods → Results → Discussion → Conclusion → References, with domain variation.
- Literature review: Abstract/summary → scope/method → thematic synthesis → disagreements/gaps → implications → conclusion.
- Technical report: executive summary → context → requirements/method → findings → implementation/analysis → risks → recommendations.
- Educational chapter: objectives → prerequisite context → explanation → examples → checks/application → summary/references.
- Policy brief: issue → evidence → options → trade-offs → recommendation/decision considerations.

Headings must reflect real conceptual structure rather than fixed paragraph counts.

## Requirements and examples

- REQ-AS-01 — outline is generated from type + audience + research question.
- REQ-AS-02 — every major section has a declared purpose.
- REQ-AS-03 — no placeholder section survives without content justification.
- REQ-AS-04 — heading hierarchy is stable enough for Word navigation and chapter splitting.
