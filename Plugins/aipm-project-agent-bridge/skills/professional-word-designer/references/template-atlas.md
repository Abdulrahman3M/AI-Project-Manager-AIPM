# Professional Template Atlas

Select a pattern by reader task, not by decoration. These are original, reusable layout recipes informed by observed public document-template categories; they do not reproduce Canva, GitHub, or any third-party template artwork.

## Executive and strategy

| Pattern | Use when | Visual grammar | Avoid |
| --- | --- | --- | --- |
| Executive Brief | leader needs a decision | title band, one-page summary, decision/recommendation box | burying the ask after background |
| Board Pack | governance review | cover, agenda/TOC, KPI panels, risk register, appendices | decorative imagery on every page |
| Strategy Paper | direction and trade-offs | north-star statement, pillars, roadmap, evidence notes | claims without owners or dates |
| Annual Impact Report | progress is evidenced | editorial cover, verified metrics, case studies, methods note | infographic numbers without data |
| Policy Brief | recommendation is time-sensitive | problem, options, recommendation, sources | academic-length introduction |
| OKR Review | goal tracking | objective cards, key-result table, confidence/risk legend | color-only status |

## Commercial and client work

| Pattern | Use when | Visual grammar | Avoid |
| --- | --- | --- | --- |
| Client Proposal | scoped commercial response | cover, challenge, approach, milestones, investment, terms | inventing customer outcomes |
| Statement of Work | contractual delivery scope | clear scope table, assumptions, timeline, acceptance | hiding exclusions in prose |
| Capability Statement | concise credentials | services, proof points, authorized case studies, contact | unverified logos or awards |
| Case Study | a verified story persuades | situation, intervention, result, evidence | causal claims beyond evidence |
| Media Kit | external profile | visual identity, audience facts, packages, contact | stale reach statistics |
| Invoice / Estimate | financial clarity | seller/buyer, items, tax, due date, payment terms | treating a visual template as tax advice |

## Research and technical

| Pattern | Use when | Visual grammar | Avoid |
| --- | --- | --- | --- |
| Research Report | evidence-led analysis | abstract, TOC, methods, results, references | manual citations/TOC |
| Literature Review | synthesis across sources | question, search scope, themes, gaps, bibliography | serial source summaries |
| Technical Guide | procedural learning | task-oriented headings, steps, code blocks, diagrams | screenshots as the only instructions |
| Architecture Decision Record | a durable technical choice | context, decision, alternatives, consequences | design without rejected options |
| Incident Report | operational learning | timeline, impact, causes, actions, owners | blame-oriented language |
| Audit Report | controls/evidence review | scope, criteria, findings, rating, management response | implying legal assurance not given |

## Education and publishing

| Pattern | Use when | Visual grammar | Avoid |
| --- | --- | --- | --- |
| Lesson Guide | guided learning | outcomes, warm-up, explanation, worked example, practice | visual clutter competing with exercises |
| Learner Workbook | repeatable practice | short prompts, answer space, checkpoints, recap | too little writable space |
| Reference Encyclopedia | deep lookup | layered headings, callouts, glossary, index, cross-references | repeating definitions instead of linking |
| Study Sheet | rapid revision | high-signal summary, tables, mnemonic boxes | long narrative paragraphs |
| Book Chapter | sustained reading | restrained opener, hierarchy, figures, notes, references | card-heavy magazine layout |
| Newsletter | recurring update | consistent masthead, 3–5 short stories, clear CTAs | a full report disguised as a newsletter |

## Operations and people

| Pattern | Use when | Visual grammar | Avoid |
| --- | --- | --- | --- |
| Project Plan | work coordination | goals, scope, RACI, milestones, risk log | Gantt-like dates without owners |
| Meeting Pack | decision-ready meeting | agenda, pre-reads, choices, action table | minutes before the meeting happens |
| Meeting Minutes | accountable record | decisions, actions, due dates, attendees | vague action verbs |
| SOP / Runbook | repeatable operation | purpose, prerequisites, numbered steps, exception path | screenshots instead of recoverable steps |
| Onboarding Guide | new-joiner orientation | welcome, first-week plan, contacts, workflows | assumed institutional knowledge |
| Employee Handbook | durable people policy | plain-language sections, callouts, version/date, contacts | unsupported legal promises |

## Directional variants

Every pattern has LTR, RTL and bilingual variants. In the RTL variant, mirror navigation, callout stripe, table visual order where semantic, footer/header alignment and process direction. In bilingual output, use a deliberate language architecture: parallel sections, a dominant base direction per paragraph, and isolated foreign runs—not manually reversed characters.
