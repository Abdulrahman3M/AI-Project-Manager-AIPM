# Source Quality and Evidence Model

Evaluate evidence by source class and task relevance, not by domain prestige alone.

## Source classes

1. Primary/original: statute, standard, dataset, experiment, official record, product specification, source code.
2. Authoritative synthesis: systematic review, professional guideline, recognized reference work.
3. Scholarly secondary analysis.
4. Reputable institutional or professional explanatory source.
5. Reputable journalism for current events and reported developments.
6. Community/experience source for experience questions only.
7. Weak/unverifiable source.

## Evaluation dimensions

Authority, directness, methodology, recency, jurisdiction/applicability, independence, traceability and relevance. Record qualitative judgments; do not invent pseudo-scientific numeric confidence.

## Requirements and examples

- REQ-SQ-01 — source class is recorded.
- REQ-SQ-02 — primary sources are preferred for authoritative claims when feasible.
- REQ-SQ-03 — freshness is assessed against the claim, not with one universal age limit.
- REQ-SQ-04 — repeated secondary reporting does not replace missing primary support.
