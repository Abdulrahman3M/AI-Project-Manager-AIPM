# Template Fidelity Mode

Use when the owner, university, publisher or organization provides a DOCX/DOTX reference template.

## Procedure

1. Preserve the supplied file as immutable input.
2. Inventory page size, margins, sections, styles, numbering, headers/footers, title pages, TOC styles, captions, tables and theme.
3. Map semantic content roles to existing template styles before inventing new styles.
4. Reuse legitimate brand assets only when supplied/authorized.
5. Do not “improve” a mandated template by silently changing its identity.
6. Record unavoidable deviations.
7. Render a representative sample and the final document against the template constraints.

## Requirements and examples

- REQ-TF-01 — supplied template is treated as authoritative when contract says so.
- REQ-TF-02 — existing semantic styles are reused before adding alternatives.
- REQ-TF-03 — unauthorized brand/logo substitution is prohibited.
- REQ-TF-04 — deviations are documented and visually verified.
