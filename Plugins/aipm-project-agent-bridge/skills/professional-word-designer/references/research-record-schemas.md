# Research Record Schemas and Worked Examples

These examples define suggested records, not runtime implementations. Replace placeholders with actual work; do not treat them as completed research.

## Document Contract example

    contract_id: DC-001
    mode: literature_review
    title: replace with approved title
    audience: replace with intended audience
    locale: en-US
    citation_style: APA 7
    page_count_basis: estimated_body_pages
    split_threshold_pages: 100
    index_filename: 00_Index.docx
    cross_file_links: test_before_claim

**Example.** Replace every placeholder and settle requested deliverables before searching. This template is not user approval.

## Claim record example

    claim_id: C-001
    text: illustrative only; not a real finding
    status: not_verified
    supporting_source_ids: []
    qualification: replace with evidence-based limit

**Example.** A claim with no supporting IDs remains not_verified; plausible wording cannot upgrade its status.

## Reproducibility package

When requested, include manuscript, source ledger, claim matrix, citation export, visual register and QA report. Include only records actually generated and protect confidential/licensed content.

**Example.** For a DOCX-only request, do not silently attach private screening notes; report verification status and add audit records only when requested or needed.
