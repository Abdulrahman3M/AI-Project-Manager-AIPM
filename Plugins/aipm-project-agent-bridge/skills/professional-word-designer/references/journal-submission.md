# Journal and Formal Submission Mode

Capture the target publication's current author instructions as evidence before formatting.

Potential requirements include title-page separation, anonymized manuscript, abstract structure, keyword limits, line numbering, word count, figure placement, reference style, supplementary files, declarations and cover letter.

A “double-blind” manuscript must remove obvious author identity from the manuscript body/properties when required, but do not destroy the owner's original file.

## Requirements and examples

- REQ-JS-01 — submission rules come from the identified target, not generic memory.
- REQ-JS-02 — anonymization is performed only when required and on a derived copy.
- REQ-JS-03 — word/figure/reference limits are checked before release.
- REQ-JS-04 — compliance report separates PASS, FAIL and UNVERIFIED.
