# Contradiction and Gap Analysis

Before synthesis, inspect the Claim–Evidence Matrix for disagreements and missing coverage.

## Contradiction protocol

- Determine whether sources actually address the same population, period, jurisdiction, measurement and definition.
- Separate factual disagreement from different scope or terminology.
- Prefer stronger/direct evidence only with stated reasoning.
- Present material unresolved disagreement fairly.
- Never average incompatible results to manufacture consensus.

## Gap protocol

Record missing primary evidence, unavailable full text, unresolved metadata, outdated evidence, missing subgroup data, and questions outside tool access. Gaps must flow into limitations and QA.

## Requirements and examples

- REQ-CG-01 — apparent conflicts are normalized for scope before judgment.
- REQ-CG-02 — material genuine conflicts are disclosed.
- REQ-CG-03 — evidence gaps are recorded with impact.
- REQ-CG-04 — synthesis never fabricates consensus.
