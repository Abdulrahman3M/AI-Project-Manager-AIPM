# Academic Document Modes and Front Matter

Select a document mode before outlining. Follow explicit university, journal, funder, regulator or user requirements first. Include only sections appropriate to the genre and evidence.

| Mode | Typical structure | Example control |
|---|---|---|
| Research paper | abstract, introduction, methods, results, discussion, limitations | Separate results from interpretation when required |
| Systematic/scoping review | question, search/method, selection, synthesis, limits | Report actual searches, not intended searches |
| Literature review | scope, thematic synthesis, comparison, gaps | Synthesize relationships, not one source per paragraph |
| Thesis chapter | chapter purpose, literature/context, argument, conclusion | Follow supplied graduate-school template |
| Technical report | summary, scope, method, findings, recommendations | Separate findings from recommendations |
| White paper | problem, evidence, options, trade-offs | Disclose relevant sponsor perspective |
| Educational chapter | objectives, explanation, worked examples, recap | Every example demonstrates the rule just taught |
| Journal manuscript | journal-specific title page, abstract, body, declarations | Verify current instructions and anonymization |
| Policy/legal analysis | jurisdiction, question, governing sources, analysis | State currentness date and controlling provisions |

**Example.** A literature review groups studies by theme and comparison; it does not claim an experiment's IMRaD results section unless the target template requires it.

## Front matter

Route title page, abstract, keywords, research question, objectives, hypotheses, methodology, scope, limitations, acknowledgments, funding, conflicts, ethics, data availability, author contributions, figure/table lists, abbreviations, glossary and appendices according to the brief and genre. Never fabricate declarations.

**Example.** If no human participants were involved, use only supplied accurate ethics facts or omit an approval statement; never invent an approval number.

## Literature synthesis and journal workflow

Cluster sources by question, population, method, measure, finding, limitation and date. Compare agreement, disagreement and gaps before drafting. For journal mode capture journal name, instructions version/date, word/abstract limits, headings, references, figure rules, blinding, line numbering, filenames and declarations. Track reviewer comments by ID, response, manuscript location, evidence/rationale and status. Claim Track Changes only if native revisions exist and were inspected.

**Example.** A reviewer asks for a new sensitivity analysis. Record the request and response; do not imply the analysis ran if only text changed.
