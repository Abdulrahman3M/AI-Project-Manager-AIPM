# Example Project Initial Review

> Fictional sample. Replace the title, scope, acceptance criteria, and commands before using this format.

## Goal

Understand the project safely and establish a verified starting point.

## Scope

- Read repository-specific instructions.
- Inspect project structure and current version-control status.
- Run only documented, relevant tests.
- Record evidence and the next concrete action.

## Out Of Scope

- Publishing, deployment, or external messages without authorization.
- Deleting user data or resetting repository state.
- Claiming unrun checks as passing.

## Acceptance Criteria

- [ ] Instructions and scope are understood.
- [ ] Working tree and relevant version-control facts are recorded.
- [ ] Tests are reported with exact commands and actual results.
- [ ] Remaining uncertainty and next action are explicit.
